DenucziTV Privacy Policy

Effective date: 9 November 2026. This policy applies to DenucziTV 0.6.3, including the Microsoft Store edition and the GitHub Windows EXE and Debian packages.

English

Who we are

DenucziTV is an open-source IPTV player maintained by Ignacio Sanguina. The application source is published at github.com/denuczi/DenucziTV. DenucziTV is a player: it does not provide, sell, host, or curate IPTV channels, movies, series, subscriptions, or provider accounts.

Data the application stores locally

DenucziTV stores the information needed to operate on your device:

  • Application preferences, language, theme, playback options, download settings, download history, and the identifier of the active account.
  • Your personal library: favorites, watch history, playback progress, and related catalog metadata.
  • Provider account metadata. Passwords and protected-connection secrets are stored in the operating system's secure credential storage (Windows DPAPI/secure storage or the Linux Secret Service), not in the developer's servers.
  • Downloaded media in the folder you choose.

This data remains on your device. The developer does not receive it, does not operate a cloud account system for it, and does not sell it. Local files can be removed through the application controls, by deleting the application data, or by uninstalling the application. Some uninstallers may leave application data; review your platform's storage settings.

Direct requests to your provider

When you connect an Xtream Codes account or a Protected Single Link, DenucziTV sends requests directly from your device to the provider you configured. Those requests can include the provider URL, credentials, an account identifier, and requests for catalogs, playback, or media downloads. The media itself is downloaded from the provider to your device. The provider's own privacy policy and terms apply. The developer does not control the provider and does not receive a copy of those requests.

Update checks and the Microsoft Store edition

DenucziTV does not include analytics, advertising SDKs, telemetry, crash-reporting uploads, or account tracking. The Windows EXE and Debian editions may contact the public GitHub Releases API to check for a newer stable version. That request goes to GitHub and may be subject to GitHub's logging and privacy practices. It does not include your provider credentials or library data.

The Microsoft Store edition is built with Store-managed updates. It does not create the GitHub updater and does not call the GitHub Releases API for update checks. Microsoft Store handles application updates, and Microsoft's own privacy terms apply to the Store service.

Diagnostics and support

The application does not upload logs or diagnostics automatically. If you choose to share a log, screenshot, or issue report, review it first: it may contain provider names, local paths, stream URLs, or account identifiers. Never publish passwords, permanent protected links, or provider secrets. Use the project's GitHub Issues for support and privacy questions.

Children

DenucziTV is a general-purpose player and is not directed to children. The content available through a provider may be subject to age ratings, regional rules, and the provider's terms. Parents and guardians are responsible for supervising use and configuring provider content.

Changes

This policy may be updated when the application's data practices change. The effective date at the top will change, and the current version will remain available in the repository. Continued use after an update means you should review the revised policy.

Español

Quiénes somos

DenucziTV es un reproductor IPTV de código abierto mantenido por Ignacio Sanguina. El código fuente se publica en github.com/denuczi/DenucziTV. DenucziTV es un reproductor: no proporciona, vende, aloja ni selecciona canales IPTV, películas, series, suscripciones ni cuentas de proveedores.

Datos que la aplicación guarda localmente

DenucziTV guarda en tu dispositivo la información necesaria para funcionar:

  • Preferencias de la aplicación, idioma, tema, opciones de reproducción, configuración e historial de descargas y el identificador de la cuenta activa.
  • Tu biblioteca personal: favoritos, historial de visionado, progreso de reproducción y metadatos relacionados del catálogo.
  • Metadatos de las cuentas de proveedor. Las contraseñas y los secretos de conexión protegida se guardan en el almacén seguro del sistema operativo (DPAPI/almacenamiento seguro de Windows o Secret Service de Linux), no en servidores del desarrollador.
  • El contenido descargado en la carpeta que elijas.

Estos datos permanecen en tu dispositivo. El desarrollador no los recibe, no opera un sistema de cuentas en la nube para ellos y no los vende. Puedes eliminarlos con los controles de la aplicación, borrando los datos de la aplicación o desinstalándola. Algunos desinstaladores pueden conservar datos; revisa el almacenamiento de tu plataforma.

Solicitudes directas a tu proveedor

Cuando conectas una cuenta Xtream Codes o un enlace único protegido, DenucziTV envía solicitudes directamente desde tu dispositivo al proveedor que hayas configurado. Esas solicitudes pueden incluir la URL del proveedor, credenciales, un identificador de cuenta y peticiones para consultar el catálogo, reproducir contenido o descargar archivos. Los archivos multimedia se descargan del proveedor a tu dispositivo. Se aplican la política de privacidad y los términos del proveedor. El desarrollador no controla al proveedor ni recibe copia de esas solicitudes.

Comprobaciones de actualización y edición de Microsoft Store

DenucziTV no incluye analítica, SDK de publicidad, telemetría, envío de informes de fallos ni seguimiento de cuentas. Las ediciones EXE de Windows y Debian pueden consultar la API pública de versiones de GitHub para buscar una versión estable más reciente. Esa solicitud va a GitHub y puede estar sujeta a sus prácticas de registro y privacidad. No incluye las credenciales de tu proveedor ni los datos de tu biblioteca.

La edición de Microsoft Store se compila con actualizaciones gestionadas por la Store. No crea el actualizador de GitHub ni consulta la API de versiones de GitHub. Microsoft Store gestiona las actualizaciones y se aplican sus propios términos de privacidad.

Diagnóstico y soporte

La aplicación no sube registros ni diagnósticos automáticamente. Si decides compartir un registro, una captura o un informe, revísalo antes: puede contener nombres de proveedores, rutas locales, URL de streaming o identificadores de cuenta. Nunca publiques contraseñas, enlaces permanentes protegidos ni secretos del proveedor. Usa GitHub Issues para soporte y cuestiones de privacidad.

Menores

DenucziTV es un reproductor de propósito general y no está dirigido a menores. El contenido disponible a través de un proveedor puede estar sujeto a clasificaciones por edad, normas regionales y los términos del proveedor. Los padres y tutores son responsables de supervisar el uso y configurar el contenido del proveedor.

Cambios

Esta política puede actualizarse cuando cambien las prácticas de datos de la aplicación. La fecha de entrada en vigor de la parte superior cambiará y la versión actual permanecerá disponible en el repositorio. Si continúas usando la aplicación tras una actualización, debes revisar la política revisada.
