Descarga e instala.

Versión estable 0.6.2. No necesitas Flutter, Git ni un compilador: elige el instalador de tu sistema.

Windows

Instalador .exe

Windows 10 / 11x64Incluye runtime de Visual C++
  1. Descarga DenucziTV-Setup-0.6.2-x64.exe.
  2. Ejecuta el instalador y sigue los pasos.
  3. Abre DenucziTV desde el menú Inicio.
Si Windows muestra una advertenciaEl instalador no está firmado digitalmente. Pulsa Más información y luego Ejecutar de todas formas.
Descargar .exe
Linux

Paquete .deb

DebianUbuntux64 (amd64)
  1. Descarga el archivo .deb.
  2. Abre una terminal en esa carpeta y ejecuta:
# Instala el paquete
sudo apt install ./denuczitv_0.6.2+1-1_amd64.deb

# Inicia la aplicación
denuczitv

Compilado e instalado en Debian 13 amd64. Otras versiones de Debian o Ubuntu deben cumplir los requisitos de bibliotecas nativas; los sistemas antiguos pueden no ser compatibles.

Preguntas frecuentes

No. Necesitas tu propia cuenta con un proveedor compatible (Xtream Codes o Enlace Único Protegido). La app solo reproduce lo que ese servicio te ofrece.

Sí. DenucziTV se publica bajo licencia MIT y su código está disponible en GitHub.

El instalador no tiene firma Authenticode, así que Windows puede marcar al editor como desconocido. Puedes verificar la descarga comparando el hash SHA256 publicado en la release.

El paquete .deb está probado en Debian 13 amd64. Otras versiones de Debian y Ubuntu pueden funcionar si cumplen los requisitos de bibliotecas nativas. No hay paquetes para otras familias de distribuciones por ahora.

No instala nada automáticamente. Busca versiones estables al iniciar o desde Configuración, y te ofrece la descarga oficial para tu sistema cuando tú decidas.
