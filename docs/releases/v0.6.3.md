# DenucziTV 0.6.3

This stable release improves dark-mode styling, episode controls, fullscreen
playback feedback, and personal-library artwork.

## What's new

- A softer circular red glow in dark mode, shared by the workspace and catalog
  header. The sidebar and light-mode backgrounds keep their existing appearance.
- Red live badges, movie playback buttons, return-to-top controls, and poster
  hover actions with white labels or icons.
- Black episode play buttons with white triangles, equally sized action areas,
  and consistent spacing between watched, download, and play controls.
- Light-green watched buttons in light mode and dark-green buttons in dark mode.
- Playback errors and retry actions remain visible in fullscreen. Retrying does
  not require leaving fullscreen.
- My Library resolves missing covers from the active catalog or provider metadata,
  including protected accounts. Artwork is isolated by account and source;
  protected artwork URLs are not written to the library database.
- Support for provider artwork in `cover` and `stream_icon` metadata fields.
- An English/Spanish project website and an updated README with download links.

## Install or upgrade

On Windows, run the `.exe` and follow the setup steps. Installation is per user.
The installer is not Authenticode-signed, so Windows may display an
unknown-publisher or reputation warning.

On Debian, download the `.deb` and its matching `.sha256` file into the same
folder, then run:

```sh
sha256sum --check denuczitv_0.6.3+1-1_amd64.deb.sha256 &&
sudo apt install ./denuczitv_0.6.3+1-1_amd64.deb
```

The Linux package was built on Debian 13 amd64. Other Debian/Ubuntu versions
must satisfy its native-library dependencies; older systems may be incompatible.

Existing users on 0.6.2 can check for this release in
**Settings > Software updates > Check for updates**. Installation remains manual;
the app does not execute installers or restart automatically.
