# DenucziTV 0.6.2 — Stable Update Checker

DenucziTV now checks for stable updates and lets you download a compatible
installer without leaving your current session.

## What's new

- Automatic startup checks, limited to once every 24 hours after a successful check.
- Stable releases only: prereleases and drafts are never offered as updates.
- An optional update notice in English and Spanish, with release notes.
- Maybe later dismisses the notice and postpones reminders for that version for
  seven days. A newer stable version can be announced sooner.
- Manual update checks in Settings, above Credits.
- Compatible installer downloads without automatic installation or restarts.

## Install or upgrade on Linux

Download both files from this release's Assets:

- `denuczitv_0.6.2+1-1_amd64.deb`
- `denuczitv_0.6.2+1-1_amd64.deb.sha256`

From the download folder:

```sh
sha256sum --check denuczitv_0.6.2+1-1_amd64.deb.sha256 &&
sudo apt install ./denuczitv_0.6.2+1-1_amd64.deb
```

The package targets x86-64 Debian/Ubuntu systems with compatible native
libraries. It is built on Debian 13; older distributions may not satisfy its
dependencies. The `.deb` is not a Windows installer. Source archives do not
contain a ready-to-install application.

## Update behaviour

Versions before 0.6.2 need this manual upgrade to obtain the update checker.
Version 0.6.2 offers future newer stable releases; it does not offer itself again.
Installation remains manual. DenucziTV does not execute installers, request
administrator privileges, or restart itself.

This release preserves manual Xtream and Protected Single Link connections.
DenucziTV does not include channels, subscriptions, or provider accounts.
