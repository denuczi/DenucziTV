# DenucziTV 0.6.4

DenucziTV 0.6.4 improves Live TV keyboard navigation, the personal library,
playback reliability and the presentation of update announcements.

## Highlights

### Change Live TV channels from the keyboard

- Type a channel number (`0`–`9`, including the numeric keypad). The player
  changes channels five seconds after the last digit, or immediately with `Enter`.
- Press `Up`/`Down` or `W`/`S` to move through the full Live TV lineup without
  leaving the player. `Backspace` edits and `Escape` cancels a pending number.
- A temporary on-screen indicator shows the channel number, name and logo when
  a keyboard channel change is requested. Long titles and missing artwork are
  handled with a high-contrast fallback.
- Channel numbering stays consistent even when categories or search filters
  change. Rapid requests are coordinated without opening multiple players.

### A faster, more useful personal library

- My Library opens by default; Live TV catalog loading is deferred until needed.
- Save and play Live TV favorites, browse favorites by Live TV, movies or series,
  and search inside the selected section.
- Remove all favorites for the selected account with confirmation, without
  deleting watch history, playback progress or downloaded files.
- Cached artwork reduces unnecessary network requests and can display previously
  loaded covers without requesting the full catalog.

### Better updates and playback feedback

- Update announcements now render Markdown headings, lists, links, tables and
  code snippets with responsive layout and scrollable release notes.
- Release notes no longer stop silently after the previous short text limit.
  Invalid content and external links receive defensive handling.
- Playback retry feedback and channel-switching lifecycle handling are improved,
  including failures from unavailable provider streams.

## Installation and upgrades

Choose the installer for your operating system from the assets attached to the
[official GitHub Release](https://github.com/denuczi/DenucziTV/releases/tag/v0.6.4)
and verify each download using the corresponding SHA-256 checksum file.

| Platform | Standalone release installer |
| --- | --- |
| Windows 10 / 11 x64 | `DenucziTV-Setup-0.6.4-x64.exe` |
| Debian / compatible Ubuntu amd64 | `denuczitv_0.6.4+1-1_amd64.deb` |

Verify each installer using its matching `.sha256` asset. For Debian, download
both files to the same directory and run:

```sh
sha256sum --check denuczitv_0.6.4+1-1_amd64.deb.sha256
sudo apt install ./denuczitv_0.6.4+1-1_amd64.deb
```

The standalone Windows `.exe` is not Authenticode-signed and may trigger an
unknown-publisher prompt. Existing standalone installs should be upgraded using
the corresponding installer, not an MSIX test package.

**Microsoft Store:** DenucziTV is also available at
[apps.microsoft.com/detail/9p25pqphwdvr](https://apps.microsoft.com/detail/9p25pqphwdvr).
Store versions are distributed and updated separately through Microsoft Store.
Do not assume that Store users already have version 0.6.4 until a new MSIX has
been submitted and published in Partner Center.
