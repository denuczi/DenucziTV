# DenucziTV 0.6.5

DenucziTV 0.6.5 introduces M3U playlist support for Live TV and movies, improves Xtream account setup, and refines first-time download folder selection.

## Highlights

### M3U playlists (new)

- Add a playlist from a local `.m3u`/`.m3u8` catalog file or an HTTP/HTTPS playlist URL (up to four redirects).
- Browse and play channels in **Live TV** and supported on-demand videos in **Movies**.
- Read optional extended M3U metadata such as channel names, groups, and artwork.
- Support per-entry `User-Agent`, `Referer`, and `Origin` values in pipe-style stream URLs. Playlist-specified headers take precedence over the application's default headers.
- Identify on-demand video entries by direct `.mp4`, `.mkv`, or `.avi` URLs or an explicit `#EXT-X-PLAYLIST-TYPE:VOD` hint; category names alone do not classify a stream as a movie.
- Preserve the original stream URL for M3U playback; the Xtream `.ts` / `.m3u8` format selector is not shown for M3U accounts.

**Scope:** M3U series are not supported. M3U downloads and exports are currently disabled. Playback availability depends on the source and its authorization requirements. Some HLS `.m3u8` files are media manifests, not IPTV catalog playlists.

### Faster Xtream account setup

- Paste a compatible `get.php` playlist URL into **Server URL** in the manual Xtream account dialog to extract the server address (including its port), username, and password.
- Ordinary Xtream credentials remain supported. Protected Single Link authorization and expiry policies are unchanged.

### Download folder picker

- The first-download folder prompt now closes before the native folder picker opens, avoiding competing dialogs on Windows and Linux.

## Install or upgrade

Choose the installer for your operating system, then verify its SHA-256 checksum using the accompanying file.

| Platform | Installer |
| --- | --- |
| Windows 10/11 x64 (standalone) | `DenucziTV-Setup-0.6.5-x64.exe` |
| Debian amd64 | `denuczitv_0.6.5+1-1_amd64.deb` |

**Windows:** The standalone EXE installer is unsigned and may display an unknown-publisher warning. The Microsoft Store edition is a separate update channel and is **not** updated by this GitHub Release.

**Linux:** To verify and install after downloading the DEB and its checksum file into the same folder:

```sh
sha256sum --check denuczitv_0.6.5+1-1_amd64.deb.sha256
sudo apt install ./denuczitv_0.6.5+1-1_amd64.deb
```

Existing accounts and local library data are intended to remain available after an in-place upgrade. Back up important local data before upgrading and report any regression with the operating system, installer version, and reproducible steps.

DenucziTV does not supply channels, playlists, content, subscriptions, or provider credentials. Users must use sources they are authorized to access.
